# 辩论协议与转达话术模板

## 协议全文（开局发给第一位 AI）

```
【辩论任务】<题目>。你将与另一个AI模型进行多轮辩论，人类负责转达双方回答。

【辩论协议】每轮输出格式：① 对对方答案的批判（事实错误/逻辑漏洞/遗漏角度）② 你坚持或让步的说明 ③ 修订后的完整答案 ④ 满意度表态：【满意】或【不满意】。规则：不做无意义让步；除非对方证据充分，否则坚持你的观点；可引用权威依据。

请给出你的初始答案。
```

## 转达话术模板

### R1 转批判（给第二位 AI）

```
【转达】这是对手 AI 的<初始回答>。请按【辩论协议】批判它：指出事实错误、逻辑漏洞、遗漏角度，并给出你的修订版完整答案。

【对手的<回答>】
<对方完整回复内容>
```

### R2 转回应（给第一位 AI）

```
【转达】这是对手 AI 对你的批判和修订版，请按【辩论协议】逐条回应：哪些批评你接受、哪些你反驳（给出理由），并给出你的新修订版完整答案。

【对手的回应】
<对方完整回复内容>
```

### R3 收尾（给第二位 AI）

```
【转达】这是对手 AI 对你批判的逐条回应和修订版。本轮为最后一轮，请给出你的最终回应：哪些接受、哪些反驳，最终修订版完整答案，以及最终满意度表态。

【对手的回应核心】
<对方完整回复内容>
```

## 转达消息编写规则

- 完整转达实质内容：对方立场、每条批判/反驳、对比表、排序、引用的权威依据
- 保持可核查性：原文引用用引号，转述明确标注
- 协议只在开局发给第一位 AI；后续轮次用「按【辩论协议】」引用，不重复粘贴协议全文
- 若中途更换辩论题目，把题目替换进协议模板即可，流程不变
